Pustaka-Booking
Aplikasi manajemen peminjaman buku sederhana berbasis web, dibangun untuk memenuhi tugas mata kuliah Web Programming 2 dan 3 di UBSI.
Catatan: Proyek ini mungkin tidak berjalan 100% sempurna karena sifatnya sebagai proyek pembelajaran.
Teknologi
    •	Framework: CodeIgniter
    •	Template Admin: sbAdmin
    •	Database: MySQL
Instalasi
Prasyarat
    •	XAMPP (atau web server lain yang mendukung PHP dan MySQL)
    •	PHP versi 5.6 atau lebih baru
    •	MySQL
Langkah-langkah
    1.	Clone atau download repositori ini
    2.	Letakkan folder pustaka-booking di dalam direktori htdocs XAMPP
    3.	Import database:
        o	Buka phpMyAdmin
        o	Buat database baru
        o	Import file SQL yang disediakan
    4.	Konfigurasi koneksi database jika diperlukan (file config terletak di application/config/database.php)
